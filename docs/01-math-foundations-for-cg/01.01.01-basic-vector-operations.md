# Basic Vector Operations

## Vector Addition

Geometrically adding two vectors is quite simple. The vector $\mathbf{c}$ is the sum of vector $\mathbf{a}$ and vector $\mathbf{b}$.


$$
\mathbf{c} = \mathbf{a} + \mathbf{b}
$$

We can construct vector $\mathbf{c}$ by 'displacing' vector $\mathbf{b}$ to 'start' at the head of $\mathbf{a}$. By displacing the vector, we aren't changing any of its properties, since as mentioned in the [previous chapter](01.01-vectors), a vector's properties does not hold a fixed location.

Performing this step gives us vector $\mathbf{b'}$. Next we just create a new vector starting at the tail of vector $\mathbf{a}$ and ending at the head of the displaced vector $\mathbf{b'}$, and that gives us vector $\mathbf{c}$.

The method of adding two vectors in this fashion is also commonly referred to as the **Head-to-Tail Rule**.

To take it a step further, we could have also said:

$$
\mathbf{c} = \mathbf{b} + \mathbf{a}
$$

But when we apply the same steps as before for vector addition, we see that we get the same result. We can say that the order in which we add two vectors together does not matter, vector addition has the commutative property.

$$
\mathbf{c} = \mathbf{a} + \mathbf{b} = \mathbf{b} + \mathbf{a}
$$

Together, $\mathbf{a}$, $\mathbf{b}$, $\mathbf{a'}$, and $\mathbf{b'}$ form a parallelogram, with $\mathbf{c}$ running along its diagonal from $\mathbf{a}$ and $\mathbf{b}$'s shared tail to the opposite corner. This is why vector addition constructed this way is also sometimes referred to as the **Parallelogram Rule**, it's the same result as the Head-to-Tail Rule, just viewed as one geometric shape instead.

Adding two vectors algebraically is incredibly simple. To add two vectors, you simply add their corresponding components together.

$$
\mathbf{a} + \mathbf{b} = (a_x + b_x,\ a_y + b_y,\ a_z + b_z)
$$

**Example:** take the same $\mathbf{a}$ and $\mathbf{b}$ from the diagrams above, $\mathbf{a} = (2, 0, -3)$ and $\mathbf{b} = (1.5, 0, 2)$.

$$
\mathbf{a} + \mathbf{b} = (2 + 1.5,\ 0 + 0,\ -3 + 2) = (3.5, 0, -1)
$$

Which is exactly $\mathbf{c}$, matching the geometric construction. This works the same way no matter how many dimensions the vectors have:

$$
\mathbf{a} + \mathbf{b} = (a_1 + b_1, a_2 + b_2, ..., a_n + b_n)
$$

## Scalar Multiplication

Scalar multiplication is the multiplication of a number $k$ with a vector $\mathbf{v}$. This results in the product of the two being another vector $k\mathbf{v}$, which is a scaled version of vector $\mathbf{v}$.

For a whole number like $3$, scalar multiplication is just repeated addition:

$$
3\mathbf{v} = \mathbf{v} + \mathbf{v} + \mathbf{v}
$$

But $k$ isn't limited to whole numbers, it can be any real number, including fractions and negatives. See below for what that looks like.

As long as $k$ is positive, $k\mathbf{v}$ points in the same direction as $\mathbf{v}$, only its length changes, stretching for $k > 1$ and shrinking for $0 < k < 1$.

<Vector3D :extent="5" :grid="true" :axes="true" :vectors="[
  { from: [0, 0, 0], to: [1, 0, 2], color: '#3cace0', label: 'v' },
  { from: [-3, 0, -2], to: [-1, 0, 2], color: '#e0793c', label: '2v' },
  { from: [2, 0, -2], to: [2.5, 0, -1], color: '#1cad4e', label: '0.5v' },
]" />

For $k <= -1$, $k\mathbf{v}$ instead points in the exact opposite direction of $\mathbf{v}$, while its length still scales by $k$'s absolute value. This means that if $k = -1$, the vector keeps its length but has an opposite direction: $-1*\mathbf{v} = -\mathbf{v}$.

<Vector3D :extent="5" :grid="true" :axes="true" :vectors="[
  { from: [0, 0, 0], to: [2, 0, 1], color: '#3cace0', label: 'v' },
  { from: [0, 0, 0], to: [-3, 0, -1.5], color: '#d61c1c', label: '-1.5v' },
]" />

And lastly, if $k = 0$, then the multiplication results in the zero vector, removing the vector's direction and making its length $0$.

Algebraically, multiplying a vector by a scalar means multiplying each of its components by that scalar:

$$
k*\mathbf{v} = (k * v_x,\ k * v_y,\ k * v_z)
$$

This again holds true for any amount of dimensions the vector has:

$$
k*\mathbf{v} = (k * v_1, k * v_2, ..., k * v_n)
$$

Scalar multiplication is also distributive, both over vector addition and over scalar addition. Scaling a sum of vectors gives the same result as scaling each vector separately and then adding them:

$$
k(\mathbf{a} + \mathbf{b}) = k\mathbf{a} + k\mathbf{b}
$$

And adding two scalars before scaling gives the same result as scaling by each separately and then adding:

$$
(k_1 + k_2)\mathbf{v} = k_1\mathbf{v} + k_2\mathbf{v}
$$

<Proof title="(extra) Why scalar multiplication is distributive">

Both properties follow directly from the component-wise definition of scalar multiplication, since distributing a scalar over a sum reduces to regular real-number distributivity, applied to each component in turn.

Take $\mathbf{a} = (a_x, a_y, a_z)$ and $\mathbf{b} = (b_x, b_y, b_z)$. Expanding $k(\mathbf{a} + \mathbf{b})$ component-wise, then distributing $k$ over each component since that's just regular real-number distributivity:

$$
\begin{aligned}
k(\mathbf{a} + \mathbf{b}) &= k(a_x + b_x,\ a_y + b_y,\ a_z + b_z) \\
&= (ka_x + kb_x,\ ka_y + kb_y,\ ka_z + kb_z) \\
&= (ka_x, ka_y, ka_z) + (kb_x, kb_y, kb_z) \\
&= k\mathbf{a} + k\mathbf{b}
\end{aligned}
$$

**Example:** take the same $\mathbf{a} = (2, 0, -3)$ and $\mathbf{b} = (1.5, 0, 2)$ from the very first diagrams on this page, with $k = 2$. Since $\mathbf{a} + \mathbf{b} = (3.5, 0, -1)$:

$$
k(\mathbf{a} + \mathbf{b}) = 2 \cdot (3.5, 0, -1) = (7, 0, -2)
$$

$$
k\mathbf{a} + k\mathbf{b} = (4, 0, -6) + (3, 0, 4) = (7, 0, -2)
$$

Both sides match, as they should.

The same reasoning applies to $(k_1 + k_2)\mathbf{v}$, distributing over each component in turn:

$$
\begin{aligned}
(k_1 + k_2)\mathbf{v} &= ((k_1+k_2)v_x,\ (k_1+k_2)v_y,\ (k_1+k_2)v_z) \\
&= (k_1v_x + k_2v_x,\ k_1v_y + k_2v_y,\ k_1v_z + k_2v_z) \\
&= k_1\mathbf{v} + k_2\mathbf{v}
\end{aligned}
$$

</Proof>

## Normalization of a Vector

Normalizing a vector means to divide a vector by its own length. This causes the vector to become a unit vector, while still having the same direction.

$$
\hat{\mathbf{v}} = \frac{\mathbf{v}}{\lVert \mathbf{v} \rVert}
$$

:::danger Zero Vector
You can't normalize the zero vector $\mathbf{v} = (0, 0, 0)$. Its magnitude is $0$, so $\frac{\mathbf{v}}{\lVert \mathbf{v} \rVert}$ divides by zero, which is undefined.
:::

Dividing a vector isn't really its own separate operation, division is just multiplication by the reciprocal. Dividing $\mathbf{v}$ by a nonzero scalar $s$ gives the exact same result as multiplying $\mathbf{v}$ by $\frac{1}{s}$:

$$
\frac{\mathbf{v}}{s} = \frac{1}{s}\mathbf{v}
$$

Which means normalizing a vector is really just scalar multiplication by $\frac{1}{\lVert \mathbf{v} \rVert}$, everything covered earlier in [Scalar Multiplication](#scalar-multiplication) applies here too.

**Example:** take $\mathbf{v} = (3, 0, 4)$. Its magnitude is $\lVert \mathbf{v} \rVert = \sqrt{3^2 + 0^2 + 4^2} = \sqrt{25} = 5$. Normalizing means multiplying by the reciprocal $\frac{1}{5}$:

$$
\hat{\mathbf{v}} = \frac{1}{5}(3, 0, 4) = (0.6,\ 0,\ 0.8)
$$

<Proof title="(extra) Why dividing by the magnitude gives a unit vector">

We want to show that $\hat{\mathbf{v}} = \dfrac{\mathbf{v}}{\lVert \mathbf{v} \rVert}$ always has magnitude $1$, for any nonzero vector $\mathbf{v}$.

Let $k = \dfrac{1}{\lVert \mathbf{v} \rVert}$, so $\hat{\mathbf{v}} = k\mathbf{v}$. Using the component-wise definition of scalar multiplication and then the magnitude formula:

$$
\begin{aligned}
\lVert \hat{\mathbf{v}} \rVert &= \lVert k\mathbf{v} \rVert = \sqrt{(kv_x)^2 + (kv_y)^2 + (kv_z)^2} \\
&= \sqrt{k^2(v_x^2 + v_y^2 + v_z^2)} \\
&= \sqrt{k^2} \cdot \sqrt{v_x^2 + v_y^2 + v_z^2} \\
&= |k| \cdot \lVert \mathbf{v} \rVert
\end{aligned}
$$

Since $\mathbf{v}$ is nonzero, $\lVert \mathbf{v} \rVert > 0$, so $k = \dfrac{1}{\lVert \mathbf{v} \rVert}$ is positive too, meaning $|k| = k$. Substituting that back in:

$$
\lVert \hat{\mathbf{v}} \rVert = \frac{1}{\lVert \mathbf{v} \rVert} \cdot \lVert \mathbf{v} \rVert = 1
$$

At last the division and multiplication by $\lVert \mathbf{v} \rVert$ cancel each other out, leaving us with $\lVert \hat{\mathbf{v}} \rVert = 1$. Which is the definition of a unit vector.

</Proof>

:::info Terminology
The terminology can be confusing at times, so to make sure:

| Term | Meaning |
| --- | --- |
| norm | the length of a vector |
| normalizing | the act of dividing a vector by its own length, turning it into a unit vector |
| normalized vector | another name for a unit vector, describing it by the process used to get there (a.k.a. normalization) |
| normal vector | **not** the same as a *normalized* vector, this one will be explained properly later, just keep in mind that it's a different thing |
:::

## Vector Subtraction

We went over vector addition, but skipped over subtraction. And there is a good reason for that: we first had to see scalar multiplication. Subtracting two vectors $\mathbf{a}$ and $\mathbf{b}$ is the same as adding vectors $\mathbf{a}$ and $-\mathbf{b}$:

$$
\mathbf{a} - \mathbf{b} = \mathbf{a} + (-\mathbf{b})
$$

And as we saw with scalar multiplication, $-\mathbf{b}$ is just $-1 * \mathbf{b}$. So vector subtraction is just the addition of the left operand vector with the product of the right operand with $-1$.

$$
\mathbf{a} - \mathbf{b} = \mathbf{a} + (-1 * \mathbf{b})
$$

Subtraction also gives us a way to construct a free vector between any two points. Recall from the previous chapter that a point and its position vector share the same components. So given two points $P$ and $Q$ with position vectors $\mathbf{p}$ and $\mathbf{q}$, the free vector pointing from $P$ to $Q$ is just the position vectors subtracted from each other:

$$
\overrightarrow{PQ} = \mathbf{q} - \mathbf{p}
$$

**Example:** take $P = (1, 0, 2)$ and $Q = (4, 0, -2)$.

$$
\overrightarrow{PQ} = (4, 0, -2) - (1, 0, 2) = (3, 0, -4)
$$

Since $\overrightarrow{PQ}$ is a vector like any other, we can take its magnitude, and doing so gives us the distance between $P$ and $Q$:

$$
d(P, Q) = \lVert \overrightarrow{PQ} \rVert = \lVert \mathbf{q} - \mathbf{p} \rVert
$$

**Continuing the example:**

$$
d(P, Q) = \lVert (3, 0, -4) \rVert = \sqrt{3^2 + 0^2 + (-4)^2} = \sqrt{25} = 5
$$

:::warning Order
Do note that to get the vector from $P$ *to* $Q$, you subtract $\mathbf{p}$ from $\mathbf{q}$. So you do $\mathbf{q} - \mathbf{p}$. If you were to do $\mathbf{p} - \mathbf{q}$, you instead get the vector from $Q$ to $P$, which has an opposite direction compared to vector $\overrightarrow{PQ}$.
:::
